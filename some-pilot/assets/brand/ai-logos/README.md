# AI logos

Square symbols for the logo tiles in `scripts/blender/compose_ai_cards.py`, rendered from Wikimedia Commons (fetched 2026-11-15), trimmed and saved at max 512 px.

Lookup: model graphics use `<model-slug>.png`, then the model family (e.g. `claude.png`), then the lab. The lab graphic uses the lab file first, then the family of its best model. Labs whose only Commons logo is a wide wordmark (Anthropic, Alibaba, Tencent) use their model family's symbol; Tencent has none and gets a monogram tile.
