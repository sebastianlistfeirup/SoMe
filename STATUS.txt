UDFØRT
- Hele mini-biblen er implementeret som en nøglefri pilot med tydelige eksterne blokeringer.
- Dateret research 2026-11-08: 43 reelle observationer, JSON + CSV, 14 niche-/sprogscores, metode og ti videoidéer.
- Foreløbig hovedniche: EN pc-hardware/handheld købsvejledning. Reserve: EN gaming-explainers. Platforme: YouTube + Instagram.
- Python/FastAPI/Jinja2/HTMX-dashboard med syv visninger, Argon2-login, server-side sessions, udløb, ratebegrænsning, CSRF og beskyttede medier.
- SQLAlchemy/Alembic, SQLite WAL/foreign keys/busy timeout, alle kontrakttabeller og revisionshistorik.
- Persistent jobkø med atomisk claim, leases, idempotens, retryloft, heartbeat og planlagte research/metrics/læring/backup/oprydningsjobs.
- Vertikal pipeline: emne -> originalt demo-/Claude-manuskript -> separat påstandskontrol -> rettighedsryddet syntetisk asset -> speak -> Whisper -> valideret klippeplan -> FFmpeg -> tekniske/sikkerheds-/kvalitetschecks -> AWAITING_OWNER.
- Versionsoutput: video.mp4, captions.srt, thumbnail.jpg, post.json, claims.json, rights.json, checks.json, clip_plan.json, storyboard.jpg og manifest.json.
- Central godkendelse med fuld video-visning og SHA-256-binding af video, thumbnail, tekst, links, platform og konto.
- Manuel ZIP-eksport, YouTube resumable upload med eksplicit privacy, Meta containerflow, TikTok-manual-only interface og RECONCILE_REQUIRED ved usikkert resultat.
- Tidsbegrænsede HMAC-signerede medielinks til godkendte versioner; signatur, udløb og aktuel hash kontrolleres.
- Metrics CSV og YouTube Analytics-flade med metric definitionsversion og NULL for ukendte værdier.
- Lærende hjerne med features før publicering, aldersmatchede metrics, median/spredning/sample size, eksterne signalsammenligninger, 80/20-eksperimenter og afdæmpede prioritetsmultiplikatorer.
- Versionsstyrede promptændringer med begrundelse og rollback. Demo-læring kan ikke overskrive eller påvirke produktionslæring. Ingen selvændrende kode/politikker eller automatisk fine-tuning.
- Budgetreservation med atomisk månedlig grænse, jobgrænse, faktiske tokens/omkostninger og usikre timeoutomkostninger.
- SSRF-sikker downloader med HTTPS, DNS/IP-filter, redirectgrænse, størrelsesgrænse, content-type, filsignatur og karantæne.
- Docker Compose web/worker som uid/gid 10001, loopback-only webport, mem/cpu-grænser, cap_drop, no-new-privileges, logrotation og healthchecks.
- Python base-image-digest og samtlige direkte/transitive Python-versioner fastlåst.
- Ubuntu/Docker-installation, deploy, backup, restore og drift dokumenteret.
- Lokal backup via SQLite Online Backup API med integritets-/hashcheck; retention og midlertidig oprydning implementeret.
